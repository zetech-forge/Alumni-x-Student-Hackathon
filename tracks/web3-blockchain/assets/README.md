# Starter kit moved

The supported Web3 starter kit is now maintained at
**[zetech-forge/web3_starter-kit](https://github.com/zetech-forge/web3_starter-kit)**.

Do not install or develop from this archived copy. It does not contain the
current contract implementations, deadline-boundary fixes or setup behavior.
Use the dedicated repository's root-level contracts, tests, scripts, frontend
and agent, and follow its
[developer README](https://github.com/zetech-forge/web3_starter-kit#readme).
