# Web3 & Blockchain: Curated Resources

Start with the first category and read in order. Everything listed is free. Links to the modules that use these are in [Content & Curriculum](content.md).

## Start here: absolute beginners

| Resource | Type | Free/Paid | Why it's useful |
|---|---|---|---|
| [What is Ethereum?](https://ethereum.org/en/what-is-ethereum/) | Explainer | Free | Plain-language first read on what the chain is and why it exists. |
| [What is Web3?](https://ethereum.org/en/web3/) | Explainer | Free | Puts blockchain apps next to the web you already use. |
| [Intro to Ethereum](https://ethereum.org/en/developers/docs/intro-to-ethereum/) | Explainer | Free | The core ideas in one page, written for developers. |
| [Wallets](https://ethereum.org/en/wallets/) | Explainer | Free | What a wallet is and why the private key must stay secret. |
| [Accounts](https://ethereum.org/en/developers/docs/accounts/) | Reference | Free | The difference between a person's account and a contract's account. |
| [Transactions](https://ethereum.org/en/developers/docs/transactions/) | Reference | Free | How a change reaches the chain, step by step. |
| [Gas and fees](https://ethereum.org/en/developers/docs/gas/) | Reference | Free | Why every action costs something, and what that means for your design. |
| [Smart contracts](https://ethereum.org/en/developers/docs/smart-contracts/) | Reference | Free | The central idea of the track, explained simply. |
| [Glossary](https://ethereum.org/en/glossary/) | Reference | Free | Look up any unfamiliar word without leaving the page. |

## Tools & setup
Do this before the event. The [Starter Kits](starter-kits.md) page has the step-by-step guides.

| Challenge | What to install |
|---|---|
| A: The Pledge | Nothing. A web browser and [Remix](https://remix.ethereum.org) are enough. |
| B: The Commons | [Node.js](https://nodejs.org/en/download) 22.13 or later, [Git](https://git-scm.com/downloads) and a code editor such as [Visual Studio Code](https://code.visualstudio.com/). |
| C: Leashed Agent | The same as B, plus access to an AI model: a hosted provider's API key, or [Ollama](https://ollama.com/download) for a local model. |

You do not need real money or a faucet. Challenge A runs on Remix's built-in test chain, and the starter kit runs a practice chain with funded wallets on your own laptop.
