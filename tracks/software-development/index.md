# Software Development

This track is about building real, working software against a tightly scoped problem in two days -- not a toy demo. You'll pick one of three challenges (data reconciliation, offline-first apps, or agentic AI/RAG), choose a Sustainable Development Goal your solution serves, and ship something that actually runs.

It suits any skill level: Challenge A (data reconciliation) is the most approachable starting point if you're newer to building end-to-end projects; Challenge C (agentic AI/RAG) has the highest ceiling if your team already has some ML/LLM experience.

See [Content & Curriculum](content.md) to prepare, [Curated Resources](resources.md) for tools and docs, [Track Rules & How to Compete](rules.md) for judging and submission details, and [Challenges](challenges.md) for the full problem statements.
